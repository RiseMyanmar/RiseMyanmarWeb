# Help Myanmar Rise - Project Description

## One-Line Summary
Open-source web platform coordinating Myanmar earthquake relief through real-time resource tracking, interactive mapping, and community collaboration.

## Short Description

**Help Myanmar Rise** is an open-source, community-driven web platform that coordinates earthquake relief efforts in Myanmar. The application provides real-time resource tracking, interactive mapping, and multilingual support to connect donors, volunteers, and organizations for efficient disaster response and recovery coordination.

## Key Features Summary
- 🗺️ **Interactive Resource Mapping** - Visualize relief needs across affected regions
- 📊 **Real-Time Tracking** - Submit and monitor resource requirements and donations  
- 🌐 **Bilingual Interface** - English and Burmese (မြန်မာစာ) language support
- 📰 **Live News Updates** - Latest earthquake relief news integration
- 🔐 **Verified Submissions** - Authenticated organizations can submit resource needs
- 💝 **Donation Coordination** - Discover and contribute to trusted relief campaigns

## Technical Stack
**Frontend:** React, Mapbox GL, Auth0 Authentication  
**Backend:** Node.js, Express.js, MongoDB  
**APIs:** Google Translate, GNews, Google Geocoding

## Purpose
A centralized platform improving disaster response efficiency, transparency, and accountability in Myanmar's earthquake relief efforts through technology and community collaboration.
